# RedVecina


## Fotos de ejemplo

Las fotos de `img/trabajos/` vienen de Wikimedia Commons (dominio público, CC0, CC BY y CC BY-SA). El autor, la licencia y el enlace a la fuente de cada una están en la constante `FOTOS` de `app.js`, y se muestran debajo de cada foto en la galería. Si se reemplaza una foto, hay que actualizar también su crédito.

## Comunas y barrios

`comunas.js` tiene las 16 comunas y los 5 corregimientos de Medellín con sus barrios y veredas, según el Decreto 346 de 2000 (tomado de los artículos de cada comuna en Wikipedia en español). Las áreas institucionales sin población residente, como universidades o parques, no aparecen. El campo `c` es el centro aproximado de cada comuna: solo se usa para ordenar por cercanía y ubicar los pines del mapa, nunca como dirección de nadie.
